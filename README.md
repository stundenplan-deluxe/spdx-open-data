# spdx-open-data

Data that [Stundenplan Deluxe](https://stundenplan-deluxe.de) derives from open sources and shares, either because a
source license requires it (share-alike) or because it is useful on its own. Each dataset lives in its own directory
with a README that names its sources, their licenses, the rules used to build it and how to regenerate it.

| Directory | Dataset | License |
|---|---|---|
| [`city-data/`](city-data/) | Germany: postal code -> municipality reference list from OpenStreetMap (OpenPLZ) and Destatis | data [ODbL 1.0](LICENSE-ODbL.txt), scripts [MIT](LICENSE-MIT.txt) |

## Licenses

Each dataset's README states the license of its data and the attribution its sources require. Unless a dataset says
otherwise, scripts are licensed under the MIT License (`LICENSE-MIT.txt`).
